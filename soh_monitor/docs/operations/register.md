# 관측소 등록

화면만으로 등록 → 연결 시험 → 첫 수집 → 상태 확인까지 한다.

1. 관리자 또는 운영자로 로그인한다. VIEWER 는 등록 버튼이 없다.
2. **관측소 → 등록**. 네트워크 코드·관측소 코드·이름·위경도·전원 구성을 넣는다.
3. 기록계 Adapter 를 고른다. 운영 대상은 `nanometrics.centaur.ctr` 이다.
   확장성 시험용 `acme.mock.recorder` 도 목록에 보인다. 센서·외부 SOH 가 없는
   모델이라 해당 탭은 미지원으로 표시되어야 한다.
4. 수집 방식:
   - DIRECT: 중앙이 기록계에 직접 붙는다. 호스트는 허용 대역(사설망)이어야 한다.
   - EDGE: 지역 Edge 를 고른다. Adapter 가 Edge 에 없거나 버전이 낮으면 할당이 거부된다.
5. 비밀번호 칸은 없다. `env:이름` 또는 `file:경로` 만 적는다.
6. 데이터 서버 URI 를 넣을 수 있다. 비우면 파형 연속성 검사는 미지원이다.
   `https://…/fdsnws/availability/1/query?…` 또는 `seedlink://10.0.0.8:18000/KS_A01`.
   허용 스킴은 `http` `https` `fdsnws` `seedlink` 뿐이다. 등록 뒤에도 관측소 상세
   **설정** 탭에서 ADMIN 이 바꾸거나 비울 수 있다.
7. **연결 시험**. 실패 이유를 고친 뒤 저장한다. 공인 IP 로는 나가지 않는다.
8. 저장 후 **지금 수집** 또는 다음 주기를 기다린다.
9. 관측소 상세에서 분류 상태와 Grafana 추세를 확인한다. OPERATOR 는 **연결 시험**으로
   등록된 장비 접속을 다시 확인할 수 있다. ADMIN 은 **설정** 탭에서 접속 호스트와
   `credentialReference` 를 바꾼다. 저장 때도 허용 대역만 받고 평문 비밀번호는 거절한다.
   수집을 끄면 스케줄과 **지금 수집**이 멈추고 상태는 `DISABLED`(수집 제외) 다.
   전원 구성이 프로파일과 다르면 **설정**의 장비 Override 로 그 장비만 임계를 덮는다.

CSV 일괄 등록은 같은 열을 쓴다. `=CMD` 같은 수식은 거절한다. 데이터 서버 URI 스킴과
접속 호스트 허용 대역도 화면 등록과 같다. 실패한 행 이유는 가져오기 결과에 보인다.

Edge 등록은 **Edge Collector** 화면에서 코드를 만들고 Token 을 한 번 받은 뒤 지역 서버에 넣는다.
