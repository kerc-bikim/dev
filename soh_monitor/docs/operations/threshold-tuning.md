# 임계값 튜닝

전압·온도·Mass Position 은 공통 숫자를 쓰지 않는다. 전원 구성과 센서 모델이 다르다.

## 기본 프로파일

`기본 감시 항목` 은 통신·저장소·시각·센서 상태만 켠다. 전압은 감시만 하고 알림은 끈다.

전원 구성에 맞춰 아래 프로파일을 고른다. Seed 가 만든다.

| 프로파일 | 주의 | 장애 | 지속 |
|----------|------|------|------|
| 12V 배터리 감시 | ≤ 11.8 V | ≤ 11.0 V | 5분 / 복구 10분, 연속 2회 |
| 24V 직류 감시 | ≤ 22.0 V | ≤ 20.0 V | 같음 |

GNSS Duty Cycle 장비는 `gnss.satellite_count` 로 장애를 열지 않는다.

## 파일럿에서 할 일

1. 3~5 관측소를 이틀 돌린다.
2. 열린 장애 중 실장애가 아닌 것을 [`pilot-log.md`](pilot-log.md) 에 적는다.
3. 오탐이면 hold·recovery·연속 횟수를 늘리거나 Override 를 쓴다.
4. 누락이면 임계를 당기거나 빠진 Metric 을 켠다.

기본값(계획서 8절): 통신 2/3회, 저장소 80/90%, Heartbeat 2/3회, Recording·Timing 은 지속시간으로 한 번 깜빡임을 걸러 낸다.
