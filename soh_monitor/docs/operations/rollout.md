# 전체 확대 (M10.10)

파일럿에서 오탐이 수용 수준이 된 뒤에 한다. 실장비 목록은 [`inventory.md`](../inventory.md).

1. 관측소 CSV 를 만든다. 수식 셀 없이.
2. 전원 구성별로 프로파일을 고른다 (`12V 배터리 감시` / `24V 직류 감시` / 기본).
3. DIRECT / EDGE 를 나눈다. EDGE 는 지역 Edge 가 ONLINE 인지 먼저 본다.
4. 배치로 등록하고 연결 시험 실패 분만 남긴다.
5. 첫 주기 후 수집이 없는 장비를 목록에서 걸러 재시도한다.
6. 등록 누락 없이 `GET /api/v1/stations` 수와 조사표 수가 같은지 확인한다.

이 환경에서는 확대 적용을 실행하지 못했다. 조사표가 비어 있다.
