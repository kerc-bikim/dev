# ADR 0014. 기관·사용자·역할과 조회자 읽기 전용

상태: 채택  
코드: `apps/api/app/access.py`, `apps/api/app/routers/admin.py`, `apps/web/src/editor/AdminPage.tsx`

## 결정

1. **기관.** `organizations` 테이블. 시드는 `기본 기관` 하나. 관리자가 `/admin` 에서 기관을 더 만든다.
2. **사용자.** 관리자가 조회자/편집자/관리자를 만든다. 비활성은 로그인만 막고, 아이디·표시 이름은 그대로 둔다. `삭제된 사용자`로 바꾸지 않는다.
3. **권한.** 프로젝트 단위. 멤버가 아니면 목록에도 없고 `GET` 도 404. 조회자는 보기·검증·StationXML 만. 편집·NRL·SEED·위저드·초안은 403.
4. **화면.** `/admin` 은 관리자만. 아니면 홈으로 보낸다. 조회자 편집기는 칸을 비활성화하고 `조회자 · 읽기 전용` 배지를 단다.

통과: **M0-03** 관리자가 편집자/조회자 생성. **M0-14** 조회자는 폼 비활성, XML 다운로드만 (S12 일부).
