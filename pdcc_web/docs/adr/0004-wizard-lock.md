# ADR 0004. 관측소 위저드와 epoch 잠금

상태: 채택  
코드: `apps/api/app/inventory/`, `apps/web/src/editor/`

## 결정

1. 프로젝트의 진실은 **StationXML 원문**이다. 위저드·NRL 적용은 ObsPy `Inventory.write()`로 문서를 다시 쓰지 않고 XML 트리에 Station/Channel/Response를 심는다.
2. 관측소 위저드는 식별·이름·기간·위치·NRL·채널 패턴·확인 7단계다. `마침`은 관측소 1개와 채널 N개를 만들고, 채널 끝 글자로 방위각·경사를 채운다 (Z 0/-90, N 0/0, E 90/0).
3. `현재 운영`이면 `endDate`를 넣지 않는다.
4. NRL 적용은 같은 밴드 3성분을 제안하고, 확인 창에서 채널을 빼면 그 채널은 그대로 둔다. 방위각·경사는 바꾸지 않는다.
5. 잠금 단위는 **프로젝트 안의 관측소 epoch** (`sta:{project_id}:NET.STA#start`)다. TTL 5분, heartbeat로 연장. 다른 사용자는 409와 읽기 전용이다. 초안 프로젝트가 같은 관측소 코드를 써도 잠금은 섞이지 않는다.

이번 슬라이스에 넣지 않은 것: 장비 세트, 버전 비교/되돌리기, 실행 취소, 초안 머지.
