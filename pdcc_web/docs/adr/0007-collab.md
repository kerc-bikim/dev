# ADR 0007. 장비 세트, 버전, 실행 취소, 초안 머지

상태: 채택  
코드: `apps/api/app/inventory/collab.py`, `apps/api/app/routers/collab.py`, `apps/web/src/editor/`

## 결정

1. **장비 세트**는 사용자별 센서·기록계 instconfig와 채널 패턴이다. 저장 시점 NRL catalog fingerprint가 지금과 다르면 `stale` 경고를 낸다.
2. 위저드·NRL 적용·초안 저장·복원·머지는 **버전**을 남긴다. 되돌리기는 이전 XML을 덮어쓰지 않고 **새 버전**을 만든다.
3. **실행 취소**는 저장된 편집 단위다. NRL 적용을 취소하면 적용 전 응답(또는 없음)으로 돌아간다.
4. 관측소 좌표 칸을 벗어나면 **초안**만 바뀐다. 새로고침 후 `초안 이어가기` / `마지막 버전으로`. 서버 XML이 바뀌었으면 필드마다 서버/내 값을 고르고, 자동 머지는 하지 않는다.

통과 시나리오: **S9** 초안 복구, **S13** 버전 되돌리기.
