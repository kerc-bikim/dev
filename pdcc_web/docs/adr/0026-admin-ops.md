# ADR 0026. 관리자 작업·잠금·시스템 화면

상태: 채택  
코드: `apps/api/app/routers/admin.py`, `apps/api/app/notices.py`, `apps/web/src/editor/AdminPage.tsx`

## 결정

1. 관리자 `/admin`에 공식 설계 1.3–1.5 나머지를 둔다. NRL **연결 테스트**, **카탈로그 새로고침**, 모드 **온라인 / 캐시 우선 / 오프라인**, 전체 작업 목록(프로젝트·유형·상태 필터), 실패 로그 받기, 대기 작업 취소, 잠금 **강제 해제(사유 필수)**, 시스템 한도·인용 문구.
2. 강제 해제 시 해당 편집자에게 `관리자가 잠금을 해제했습니다` 알림을 보낸다. 초안은 지우지 않는다.
3. 캐시 우선 모드는 Redis에 모드를 저장하고, 캐시가 있으면 업스트림을 치지 않는다.

통과: 관리자 화면 1.3–1.5, M2-07 강제 해제 UI.
