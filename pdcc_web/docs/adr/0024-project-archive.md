# ADR 0024. 프로젝트 보관과 관리자 복원

상태: 채택  
코드: `apps/api/app/routers/projects.py`, `apps/api/app/access.py`,
`apps/web/src/editor/ProjectHome.tsx`

## 결정

1. 편집 권한이 있는 사용자는 프로젝트 목록에서 확인 후 프로젝트를 보관할 수 있다.
2. 보관된 프로젝트는 일반 목록, 직접 조회, 편집 및 내보내기에서 숨긴다. 데이터와 기존
   프로젝트 상태는 삭제하거나 바꾸지 않고 `archived_at`, `archived_by`만 기록한다.
3. 관리자만 별도 보관 목록을 조회하고 프로젝트를 복원할 수 있다. 복원하면 프로젝트가
   일반 목록에 다시 나타나며 기존 권한과 데이터가 그대로 유지된다.
4. 보관과 복원은 각각 `project_archive`, `project_restore` 감사 기록을 남긴다.
5. 기존 데이터베이스는 API 기동 시 보관 메타데이터 열을 추가하며 기존 프로젝트는 모두
   활성 상태로 유지한다.

통과: **M4-06** 보관 프로젝트가 일반 사용자 작업 흐름에서 숨겨지고 관리자만 별도 목록에서
복원할 수 있다.
