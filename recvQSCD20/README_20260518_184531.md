# recvQSCD20 (GUI v3.2)

KIGAM QSCD20 UDP 패킷(120바이트)을 수신·기록·시각화하는 PyQt5 GUI 프로그램입니다.

## 요구 사항

- Python 3.8+

## 설치

```bash
pip install -r requirements.txt
```

## 실행

```bash
python recvQSCD20_gui.py
```

콘솔 전용 수신기: `python recvQSCD20.py` (120바이트 패킷만 `.QSCD20.bin`에 연속 저장)

## 기본 설정 (스크립트)

[recvQSCD20_gui.py](recvQSCD20_gui.py) 상단 상수에서 변경합니다.

```python
DEFAULT_PANELS = frozenset({"diff", "max", "pga"})  # Live/File 기본 ON 패널
DEFAULT_TIME_WINDOW_SEC = 600  # 시간 콤보: 60, 120, 600, 1200, 1800
LIVE_LOG_VERBOSE = False       # True면 패킷당 상세 로그(파일·화면 부하 증가)
CHART_REFRESH_MS = 200         # 차트·패킷 배치 처리 주기(ms)
```

## 사용 방법

### 수신 설정

1. **UDP Port** — 기본 `9908`
2. **로그 저장 디렉터리** / **파일 prefix**
3. **Start** / **Stop**

생성 파일:

| 파일 | 내용 |
|------|------|
| `{prefix}.QSCD.log` | 텍스트 로그 (모든 관측소) |
| `{prefix}.QSCD20.bin` | GUI 확장 바이너리 (아래 형식) |

### Live 탭

1. **시간 선택** — `60초`, `120초`, `600초`, `1200초`, `1800초`
2. **수신 관측소** — 선택 관측소만 **화면 로그·차트** 갱신 (옆 **최종 수신** KST)
3. **표시 차트** (패널별 체크박스)
   - **Time Diff** — `수신 시각 − data time` (초)
   - **Maximum** — Z, N, E
   - **PGA** — H, T
   - **WMMA** — U-D / N-S / E-W (m, M, A)
   - **TMM** — U-D / N-S / E-W (m, M)
4. **차트**
   - x축: data time **KST** `시:분:초`, 1초 격자, 빈 초는 **NaN** 공백
   - y축: Diff → `시간(초)`, 그 외 → `gal(cm/sec2)`
   - **마우스 오버**: 시각·계열 값 팝업 (차트 밖으로 나가면 숨김)
   - **드래그** 줌인 / **더블클릭** 줌아웃 (Live는 줌 중 X 자동 스크롤 중지)
5. **로그** (하단) — 선택 관측소만 표시 (`LIVE_LOG_VERBOSE=False` 시 패킷당 1줄 요약)

### File Viewer 탭

- `.QSCD20.bin` 열기 — Live와 동일한 패널·시간 창·체크박스
- **QCDX** 확장 파일: Live에서 저장한 **TimeDiff**를 그대로 Diff 차트에 표시
- 구형 120B 전용 파일: 열기 시각 기준으로 Diff 근사 (파일 정보 라벨에 안내)

## 바이너리 형식

### GUI 저장 (`QCDX` 확장)

| 구간 | 크기 | 설명 |
|------|------|------|
| 파일 헤더 | 6B | `QCDX\x01` (`BIN_FILE_MAGIC`) |
| 레코드 × N | 128B each | QSCD20 패킷 120B + TimeDiff `float64` 8B (big-endian) |

- TimeDiff = Live 수신 시 `recv_wall − myqscd[6]` (초)
- 함수: `pack_qscd20_bin_record()`, `read_qscd20_bin()`

### 콘솔 / 구형 파일

- 헤더 없이 **120B** 패킷만 연속 (`recvQSCD20.py` 출력)
- File Viewer에서 읽을 수 있으나 TimeDiff는 저장되지 않음

## 패킷 필드 ↔ 차트 (요약)

| 패널 | struct 인덱스 | 필드 |
|------|---------------|------|
| Time Diff | (저장값 또는 계산) | `recv − data time` |
| Maximum Z/N/E | 22, 23, 24 | |
| PGA H/T | 25, 26 | |
| WMMA | 7–15 | m, M, A (축별) |
| TMM | 16–21 | m, M (축별) |

Quality Flag (`myqscd[1]`): `0x00` Good / `0x01` GPS Unlock / `0x02` REBOOT / `0x03~FF` Reserved  
Station Code: `myqscd[4]`(2B) + `myqscd[5]`(3B)

## 성능 (장시간 Live)

- UDP 수신 스레드는 패킷을 **큐**에만 적재
- **200ms** 타이머에서 패킷 배치 처리·차트 1회 갱신
- 바이너리 `flush`는 32패킷마다
- 격자 캐시는 **활성 패널** 필드만 재계산
