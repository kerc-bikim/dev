recvQSCD20 UDP 수신 GUI

KIGAM QSCD20 패킷(120바이트) 수신·기록·시각화 — PyQt5 + pyqtgraph 기반 GUI 현재 v1.0

개요 설치·실행 기능 UI 명세 사용 순서 바이너리 변경 이력 설정

개요

본 프로젝트는 recvQSCD20_gui.py 기반 QSCD20 UDP 수신·시각화 GUI입니다. UDP로 데이터를 수신하고, 텍스트 로그와 .QSCD20.replay 재생 파일로 저장하며, Live 탭에서 관측소별 PGA 카드를, Detail View에서 상세 차트를, File View에서 저장 파일을 재생합니다. 매뉴얼은 GUI 프로그램만 관리합니다. 현재 버전은 1.0입니다.

Time Diff — 데이터 시각과 수신 시각

Diff 차트의 값은 패킷에 들어 있는 데이터 시각과, 이 프로그램이 UDP 패킷을 받은 수신 시각의 차이입니다. 차트 x축(KST)은 데이터 시각을 쓰고, TimeDiff는 그 데이터가 여기까지 오는 데 걸린 지연을 초 단위로 보여 줍니다.

Packet clock

데이터 시각

관측소가 패킷에 넣은 시각 myqscd[5]. 차트 x축(KST)의 기준입니다.

기능 정리 (v1.0)

현재 배포 기준 버전은 1.0입니다. 아래는 이 버전에 포함된 기능을 영역별로 정리한 것입니다. 이전 3.x 중간 이력을 나열하지 않습니다.

수신 · 저장

  • QSCD20 UDP 패킷(120바이트) 수신. TimeDiff는 GUI와 분리된 전용 수신 프로세스에서 확정
  • Linux는 커널 수신 시각(SO_TIMESTAMPNS), Windows는 recvfrom 직후 time.time_ns()
  • Start 시 {prefix}.QSCD.log(항상 상세, UTC)와 {prefix}.QSCD20.replay(패킷 + TimeDiff) 생성
  • 수신 큐가 가득 차면 먼저 받은 기록을 지키기 위해 새 패킷을 폐기하고 건수를 로그에 남김
  • Stop·프로그램 종료 시 큐에 남은 패킷을 모두 기록한 뒤 파일을 닫음

Live

  • 관측소(Station + Location)마다 카드 1장 — PGA 현재값·윈도우 누적 최대·수신 시각 타임시리즈
  • LATENCY는 수신 시 확정한 TimeDiff. 설정 시간(기본 10초) 이상 미수신이면 빨간색으로 지연 초 표시
  • 누적 최대는 선택한 타임윈도우 안의 PGA 최댓값

Detail View

  • 선택 관측소의 Time Diff, Maximum, PGA, WMMA, TMM 상세 차트
  • 최종 수신 시각, 지연 시 빨간색 깜빡임, Quality / Station / Location
  • 1초 격자·빈 초 NaN, 호버 팝업, 드래그 줌 / 더블클릭·⟲ 줌 초기화

File View

  • .QSCD20.replay 열기 — Live에서 저장한 TimeDiff를 Diff 차트에 그대로 표시
  • 파일 내 관측소 선택, 차트 줌 구간에 맞춘 짝 로그(.QSCD.log) 표시

로그 · 설정 · 도움말

  • 로그 뷰어(Ctrl+L): 하단 관측소 콤보, 화면 요약/상세 전환. 파일 로그는 항상 상세 UTC
  • 기본 설정(Ctrl+P): 저장 폴더, 포트, 시간 창, 차트 패널, 큐·지연 경고 등
  • 도움말(F1): 본 HTML. Linux는 WebEngine GPU를 끄고, 실패 시 기본 HTML 뷰어로 대체
  • 화면 시간은 기본 KST, KST/UTC 토글. 저장 값은 항상 UTC

2. 우측 수신 패널

세 탭에서 공통으로 보입니다. UDP 수신 시작·중지와 저장 파일 이름을 여기서 다룹니다.

항목설명
로그 파일명 (prefix) 저장 파일 앞부분. 예: 20260519_120000. 경로 구분자, .., <>:"|?*, 제어 문자, 끝의 점·공백, Windows 예약 이름(CON, NUL, COM1 등)은 거부합니다. 같은 이름이 있으면 Start 시 덮어쓰기 확인을 하며, 승인하면 로그와 replay를 모두 새로 씁니다.
저장 경로 안내 기본 설정의 log_save_dir / bin_save_dir (프로그램 폴더 기준 상대 경로, 기본 logs, bin)
UDP Port 수신 포트. 기본값은 설정의 default_port(보통 9908). Start 전에 변경합니다.
Start UDP 수신 시작. 관측소 버퍼·Live 카드를 비우고, 로그·replay를 엽니다.
Stop 수신 중지. 큐에 남은 패킷을 모두 기록한 뒤 파일을 닫습니다.
상태 대기 중 / 수신 중 등 현재 수신 상태

생성 파일: {prefix}.QSCD.log(모든 관측소 상세 텍스트), {prefix}.QSCD20.replay(패킷 120B + TimeDiff 8B).

3. 공통 컨트롤

컨트롤설명
시간 선택 Live·Detail View·File View 각각의 콤보. 목록은 설정 time_window_choices(예: 60 / 120 / 600 / 1200 / 1800초). 기본 선택은 default_time_window_sec.
KST / UTC 토글 각 탭 상단과 로그 뷰어 하단에 있습니다. 차트 축, 최종 수신, Last Data, 로그 화면 시각만 바꿉니다. 로그 파일과 QSCD 데이터·TimeDiff 계산은 항상 UTC(Unix epoch)입니다.
로그 뷰어 아이콘 문서+돋보기 모양. 툴팁에 Ctrl+L. Live·Detail View는 수신 로그, File View는 짝 .QSCD.log

4. Live 탭

수신 중인 모든 관측소를 한눈에 보기 위한 화면입니다. 카드는 Station 코드와 Location 조합(sta|loc)마다 하나씩 생깁니다.

상단 막대

  • 시간 선택 — 카드 타임시리즈 x축 폭과 누적 최대를 계산할 구간
  • PGA H / T — 막대와 타임시리즈 채널. 둘 다 끌 수 없으며, 하나를 끄면 나머지 하나는 유지됩니다.
  • 안내 문구: 현재값 · 누적 최대(선택 시간 창, 시각/gal) · 타임시리즈(수신 시각)
  • KST/UTC, 로그 뷰어 아이콘

관측소 카드 (왼쪽 → 오른쪽)

영역표시
파란 사이드바 Station Code, Location Code (loc 바이트 0x00은 문자 0, 예: \x00\x00 → 00), Quality(Good data / GPS Unlock / REBOOT / SPIKE), LATENCY (SEC), Last Data (HH:MM:SS)
LATENCY 평소: 마지막 패킷의 TimeDiff(recv_wall − 데이터 시각, 초, 소수 3자리). 차트 타이머로 다시 계산하지 않습니다. TimeDiff 절대값이 경고 시간(기본 10초)을 넘으면 빨간색. 마지막 수신 후 같은 시간이 지나면 빨간색으로 미수신 경과 초(소수 1자리)를 표시합니다.
현재 값 막대 마지막 패킷의 PGA H / T (gal). 막대 위에 숫자
누적 최대 막대 선택한 시간 창 안에서 H·T 각각의 최댓값. 막대 위에는 최댓값이 난 데이터 시각과 gal
타임시리즈 x축은 수신 시각(지금 기준 슬라이딩 창), y축은 gal. 곡선 H(노란계열)·T(청록). 호버 시 값 팝업. 창이 비면 빈 안내

5. Detail View 탭

한 관측소를 골라 패킷 필드를 초 단위 격자로 그립니다. x축은 데이터 시각(표시 TZ)입니다.

상단 정보 막대

  • 수신 관측소 — Start 이후 도착한 Station 코드. (관측소 선택)이면 차트·화면 패킷 로그가 비어 있습니다. 바꾸면 화면 로그를 지우고 해당 관측소만 다시 그립니다. 로그 뷰어 하단 콤보와 동기화됩니다.
  • 최종 수신 — 선택 관측소의 마지막 UDP 수신 시각. 경고 시간(기본 10초)을 넘으면 빨간 배경으로 깜빡이며 (⚠ N초 지연)을 붙입니다.
  • Quality / Station / Location — 마지막 패킷 기준. Quality는 0x00 — Good data 형식
  • KST/UTC, 로그 뷰어 아이콘

시간 · 범례 · 패널

  • 시간 선택 — 차트에 유지할 데이터 시각 구간. 안내: 드래그 줌인, 더블클릭/⟲ 줌아웃, 마우스 오버 값 팝업
  • 범례·최근값 표시 — 끄면 각 차트 범례와 패널 상단 최근값 라벨을 함께 숨깁니다. 시작 기본값은 설정 default_show_legend
  • 표시 차트 선택 — 아래 패널을 켜고 끕니다. 시작 기본 ON은 설정 default_panels(보통 Diff, Maximum, PGA)
패널곡선y축
Time Diff (recv − data)Diff초
Maximum (Z, N, E)Z / N / Egal
PGA (H, T)H / Tgal
U-D / N-S / E-W WMMAm, M, Agal
U-D / N-S / E-W TMMm, M, Agal

차트 동작

  • x축: 데이터 시각 → HH:MM:SS, 1초 칸. 빈 초는 선이 끊기도록 NaN
  • y축 gal: SI 접두(k/M) 없이 실제 값
  • 상단 최근값: — Z : 0.123456 형식, 범례와 같은 색
  • 호버: 흰 배경·검은 글씨. 위/아래에 따라 말풍선 방향을 바꿔 잘리지 않게 함. 차트 밖으로 나가면 숨김
  • 줌: 왼쪽 드래그로 구간 확대, 더블클릭 또는 패널 오른쪽 위 ⟲로 초기화. 범례는 왼쪽 위
  • Live 수신 중이면 창의 오른쪽(최신)으로 자동 스크롤. 사용자가 줌하면 자동 스크롤을 멈춥니다

6. File View 탭

저장해 둔 replay를 재생합니다. 수신 패널의 Start와는 별개입니다.

  • QSCD20.replay 열기… — QCDX\x01 헤더 + 128바이트 레코드. 열리면 관측소 목록·시간 범위를 정보 라벨에 표시
  • 시간 선택 — 표시 구간의 길이. 줌하지 않은 상태의 x축 폭
  • 관측소 — 파일에 있는 Station만 나열. 하나면 비활성. 차트와 File 로그 뷰어 관측소와 동기화
  • 범례·최근값 표시, 표시 차트 선택 — Detail View와 같은 패널 집합
  • Diff 차트는 파일에 붙은 TimeDiff를 다시 계산하지 않고 그대로 사용. 저장값이 없는 구형 파일이면 열 시각 기준 근사라는 안내
  • 로그 뷰어 아이콘: 같은 prefix의 .QSCD.log를 찾아 엽니다. 없으면 찾아보기

7. 로그 뷰어 (수신 — Live·Detail View)

팝업 창. 화면에는 선택 관측소 패킷과 Start/Stop 등 시스템 메시지가 보입니다. 디스크의 .QSCD.log는 관측소와 관계없이 항상 상세 UTC입니다.

  • 본문: 읽기 전용 로그. 최대 줄 수는 설정 log_max_lines
  • 하단 관측소 콤보 — Detail View 수신 관측소와 같음. 바꾸면 화면 로그를 지우고 그 관측소 패킷만 이어 받음
  • 상세 로그 표시 — 켜면 패킷마다 여러 줄, 끄면 한 줄 요약. 바꾸는 즉시 화면을 다시 그림. 이 체크는 저장되지 않음
  • KST/UTC, 로그 지우기

8. 로그 뷰어 (File View)

  • replay를 연 뒤에만 열 수 있습니다.
  • 상단 정보: 로그 경로, 표시 시차, 관측소, 시간 구간, 패킷 수. 너무 많으면 앞 3000개만
  • 하단 관측소 — File View 관측소와 동기화
  • 차트 줌 구간에 맞추기 — 켜면 차트에 보이는 data time 구간의 로그만. 끄면 그 관측소 로그 전체
  • 다시 읽기, 로그 파일 찾아보기…, KST/UTC

  • 프로그램 재시작 후: default_panels, default_show_legend

10. 도움말 창 (F1)

본 README.html을 렌더링합니다. http(s) 링크는 시스템 브라우저로 엽니다. Linux에서는 Chromium GPU를 끄고, 렌더 프로세스가 죽으면 기본 HTML 뷰어로 바꿉니다.

차트 공통 (Detail View · File View)

기능설명
레이아웃차트 영역 흰 배경, 로그 다크 테마, 탭·버튼은 앱 스타일시트
갱신chart_refresh_ms(기본 200ms)마다 패킷 배치(packet_drain_max)와 차트 다시 그리기
replay flushbin_flush_every 패킷마다 디스크 flush

사용 순서

  1. 필요하면 기본 설정에서 폴더·포트·시간 창을 맞춥니다.
  2. 우측 패널에 prefix와 UDP 포트를 넣고 Start 합니다.
  3. Live에서 전체 관측소 PGA를 보고, Detail View에서 한 관측소를 골라 상세 차트를 봅니다.
  4. 로그 아이콘 또는 Ctrl+L로 패킷 로그를 확인합니다. 하단에서 관측소를 바꿀 수 있습니다.
  5. Stop 한 뒤, File View에서 저장한 .QSCD20.replay를 열어 재생할 수 있습니다.

바이너리 형식

Start 시 bin_save_dir 아래에 {prefix}.QSCD20.replay 가 만들어집니다. File View는 이 확장자 파일을 엽니다.

TimeDiff = Live 수신 시 recv_wall − myqscd[5] (초). File View는 파일에 저장된 이 값을 Diff 차트에 그대로 그립니다.

API: write_qscd20_bin_header(), pack_qscd20_bin_record(), read_qscd20_bin() → QscdBinLoadResult

변경 이력

현재 버전은 1.0입니다. 기능 목록은 위의 기능 정리를 기준으로 합니다.

v1.0 현재
  • QSCD20 UDP 수신·TimeDiff 확정(전용 프로세스)·로그/replay 저장
  • Live 관측소 카드(PGA 현재값·윈도우 누적 최대·LATENCY)
  • Detail View 상세 차트, File View replay 재생
  • 로그 뷰어(관측소 선택), 기본 설정, F1 도움말

설정 파일 (recvQSCD20_gui_settings.json)

메뉴 기본 설정 (Ctrl+P)에서 수정합니다. 항목 라벨·입력란에 마우스를 올리면 한글 설명이 표시됩니다. 

log_save_dir, bin_save_dir
default_port, default_time_window_sec, time_window_choices
default_panels, default_show_legend, log_max_lines
chart_refresh_ms, packet_drain_max, packet_queue_max, bin_flush_every
recv_delay_alert_sec, recv_alert_blink_ms
sock_timeout_sec, sock_timeout_count, display_tz

default_panels 는 기본 설정에서 차트 패널 체크박스로 고릅니다. default_panels·default_show_legend 는 프로그램을 다시 시작해야, packet_queue_max 는 다음 Start 부터 반영됩니다. 저장 완료 창에서도 같은 내용을 안내합니다.
