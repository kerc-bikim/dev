recvQSCD20 UDP 수신 GUI

KIGAM QSCD20 패킷(120바이트) 수신·기록·시각화 — PyQt5 + pyqtgraph 기반 GUI 현재 v3.10

개요 설치·실행 사용법 바이너리 UI·차트 변경 이력 구현 계획 상수 plan.html

개요

본 프로젝트는 recvQSCD20_gui.py 기반 QSCD20 UDP 수신·시각화 GUI입니다. UDP로 데이터를 수신하고, 텍스트 로그·QCDX 바이너리로 저장하며, Live 탭에서 실시간 차트를, File Viewer 탭에서 저장 파일을 재생합니다. 매뉴얼은 GUI 프로그램만 관리합니다.

사용 방법

수신 (메인 우측 패널)

  1. 로그 파일명 (prefix)
  2. UDP Port — 기본 9908
  3. Start / Stop · 상태

저장 폴더는 기본 설정의 log_save_dir(기본 logs), bin_save_dir(기본 bin) — 프로그램 디렉터리 기준 상대 경로.

생성 파일내용
{prefix}.QSCD.log텍스트 로그 (모든 관측소)
{prefix}.QSCD20.replayGUI 확장 재생 파일 (QCDX, 아래 참고)

prefix에는 경로 구분자, .., <>:"|?*, 제어 문자, 끝의 점·공백, Windows 예약 이름(CON, NUL, COM1 …)을 쓸 수 없습니다. 같은 이름의 파일이 있으면 Start 시 확인 창이 뜨고, 승인하면 로그·바이너리를 모두 새로 기록합니다.

TimeDiff 와 수신 부하

  • TimeDiff(recv − data time)는 recvfrom() 직후 UDP 스레드에서 확정 — 차트·GUI 부하와 무관
  • 큐가 packet_queue_max 까지 차면 먼저 받은 기록을 지키기 위해 새 패킷을 폐기하고 건수를 로그에 남김
  • Stop·프로그램 종료 시 큐에 남은 패킷을 모두 기록한 뒤 파일을 닫음

Live 탭

  • 시간 선택 — 60 / 120 / 600 / 1200 / 1800초
  • 수신 관측소 — 선택 관측소만 화면 로그·차트 갱신
  • 최종 수신 (KST) — 선택 관측소 마지막 수신 시각 10초 이상 지연 시 빨간색 깜빡임
  • Quality / Station / Location — Quality Flag, 5B Station 코드, Location(myqscd[34])
  • 표시 차트 — Diff, Maximum, PGA, WMMA(3축), TMM(3축) 패널별 체크
  • 로그 — Live 탭 상단 우측 로그 뷰어 아이콘 (Ctrl+L); 하단 상세 로그 표시 체크로 화면을 요약/상세로 다시 그림. 파일은 항상 상세 저장

File Viewer 탭

  • QSCD20.replay 열기 — Live와 동일 패널·시간 창 (이전 .bin 도 가능)
  • 관측소 콤보박스 — 파일 내 관측소 선택 후 해당 데이터만 차트 표시
  • QCDX 파일 — Live에서 저장한 TimeDiff를 Diff 차트에 그대로 표시
  • 구형 120B-only 파일 — Diff는 파일 열기 시각 기준 근사 (라벨 안내)

바이너리 형식

GUI 저장 (QCDX 확장)

구간크기설명
파일 헤더5BQCDX\x01 (BIN_FILE_MAGIC)
레코드 × N128BQSCD20 120B + TimeDiff float64 8B (big-endian)

TimeDiff = Live 수신 시 recv_wall − myqscd[6] (초)

API: write_qscd20_bin_header(), pack_qscd20_bin_record(), read_qscd20_bin() → QscdBinLoadResult

구형 120B-only 파일

QCDX 헤더 없이 120B 패킷만 연속된 파일 — File Viewer 읽기 가능, TimeDiff 미저장(근사).

패킷 필드 (요약)

항목인덱스설명
Quality Flag[1]0x00 Good / 0x01 GPS Unlock / 0x02 REBOOT / 0x03~FF Reserved
Station Code[4]+[5]2B + 3B (5바이트)
Data Time[6]Unix epoch (초) — 차트 x축·1초 버킷
Location[34]2s — 화면 Location 라벨
Maximum Z/N/E22–24차트 max 패널
PGA H/T25–26차트 pga 패널
WMMA / TMM7–21축별 m, M, (A)

구현 계획 요약

상세 계획·데이터 흐름·모듈 설명은 plan.html을 참고하세요.

목표 (최종)

  • UDP 9908, prefix 로그/bin, Quality·Station·Location
  • Diff = recv − data time, KST x축, 1초 NaN 격자
  • 관측소 필터(Live/File), QCDX+TimeDiff, 패널별 차트
  • 성능: 큐·200ms 타이머·활성 패널 격자 캐시

데이터 흐름 (개요)

UDP Thread: recv (Linux 커널 ts / 그 외 time.time_ns) → TimeDiff 확정 → queue.Queue
         ↓ (QTimer, 패킷당 시그널 없음)
    drain(최대 packet_drain_max) → QCDX.replay / StationBuffer / 로그
         ↓
    차트 갱신 (선택 관측소)

Stop/종료: 남은 큐 전부 drain → flush → 파일 닫기

File Viewer: read_qscd20_bin → 관측소 필터 → set_static_from_records

설정 파일 (recvQSCD20_gui_settings.json)

메뉴 기본 설정 (Ctrl+P)에서 수정합니다. 항목 라벨·입력란에 마우스를 올리면 한글 설명이 표시됩니다. 

log_save_dir, bin_save_dir
default_port, default_time_window_sec, time_window_choices
default_panels, default_show_legend, log_max_lines
chart_refresh_ms, packet_drain_max, packet_queue_max, bin_flush_every
recv_delay_alert_sec, recv_alert_blink_ms
sock_timeout_sec, sock_timeout_count

default_panels·default_show_legend 는 프로그램을 다시 시작해야, packet_queue_max 는 다음 Start 부터 반영됩니다. 저장 완료 창에서도 같은 내용을 안내합니다.
