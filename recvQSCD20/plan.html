5. 데이터 · 로깅

StationBuffer

buckets[epoch_sec] — 동일 초 마지막 값; version으로 격자 캐시 무효화.

로그

  • 파일: 모든 관측소
  • 화면: StationGuiLogFilter — 선택 관측소만
  • LIVE_LOG_VERBOSE: False → 1줄 요약

UDP

UdpReceiver (QThread), timeout 0.5s 폴링(최소 0.05s), 60s 무수신 경고. recvfrom() 직후 TimeDiff를 확정해 queue.Queue에 넣고, 소켓 timeout 변경은 수신 스레드가 다음 루프에서 적용한다.

성능

항목값의미
PACKET_DRAIN_MAX800타이머 1회 처리 상한
PACKET_QUEUE_MAX20000큐 상한 — 초과 시 새 패킷 폐기
CHART_REFRESH_MS200차트·drain 주기
BIN_FLUSH_EVERY32패킷 수 기준 flush

호버 · 축

  • ChartHoverTooltip — Leave 숨김, Y 위치 자동 조절
  • PlainGalAxisItem — SI 접두 비활성
  • ChartViewBox — RectMode 줌, ⟲ 버튼 초기화

6. 데이터 흐름

UDP Thread: recvfrom → TimeDiff 확정 → queue.Queue (포화 시 새 패킷 폐기)
QTimer 200ms → _drain_packet_queue (≤ PACKET_DRAIN_MAX)
  → QCDX.bin / FileHandler / StationBuffer
  → (dirty) pyqtgraph 차트
  → logger → StationGuiLogFilter → LogView
Stop/종료 → 잔여 큐 전부 drain → flush → close

File: read_qscd20_bin → filter_records_by_station → set_static_from_records

9. 스크립트 상수

아래 값은 recvQSCD20_gui_settings.json 에서 로드하며 메뉴 기본 설정으로 편집한다. BIN_FILE_MAGIC 만 코드 고정이다. 

DEFAULT_PANELS = frozenset({"diff", "max", "pga"})
DEFAULT_TIME_WINDOW_SEC = 600
TIME_WINDOW_CHOICES = (60, 120, 600, 1200, 1800)
BIN_FILE_MAGIC = b"QCDX\x01"   # 코드 고정
CHART_REFRESH_MS = 200
PACKET_DRAIN_MAX = 800
PACKET_QUEUE_MAX = 20000
BIN_FLUSH_EVERY = 32
LIVE_LOG_VERBOSE = False
RECV_DELAY_ALERT_SEC = 10
RECV_ALERT_BLINK_MS = 500
SockTimeOut = 0.5              # 최소 0.05
SockTimeOutCount = 120
