PPSD Web Viewer 구축 계획

FDSNWS(172.31.100.100)로부터 파형/응답을 받아 ObsPy로 PPSD를 계산하고, IRIS MUSTANG 스타일 히트맵과 사용자 선택 percentile 오버레이/클리핑을 웹에서 조회할 수 있는 FastAPI + React 애플리케이션을 구축합니다.

1. 전체 구조

FastAPI(Python) 백엔드가 ObsPy로 PPSD 를 계산해 PNG 를 생성하고, React(Vite) 프론트엔드가 이를 조회/표시합니다. FDSNWS 서버(http://172.31.100.100)는 백엔드에서만 접근합니다 (프론트 CORS 문제 회피).

2. 백엔드 (FastAPI + ObsPy)

의존성 (backend/requirements.txt)

  • fastapi, uvicorn[standard], pydantic
  • obspy (PPSD, FDSN Client 포함)
  • matplotlib (Agg 백엔드), numpy
  • python-multipart, httpx

FDSN 클라이언트 래퍼 backend/app/services/fdsn_client.py

  • obspy.clients.fdsn.Client(base_url=settings.FDSNWS_URL) 를 싱글턴으로 생성.
  • list_networks/stations/channels 은 client.get_stations(level=...) 로 조회 후 pydantic 모델로 반환.
  • get_waveforms_with_response(net, sta, loc, cha, t1, t2) 는 파형과 level="response" inventory 를 함께 반환.

PPSD 서비스 backend/app/services/ppsd_service.py

핵심 계산:

from obspy.signal import PPSD
ppsd = PPSD(tr.stats, metadata=inv)
ppsd.add(st)
  • 결과 캐시: 입력 파라미터(net/sta/loc/cha/t1/t2/PPSD 파라미터) 해시를 키로 cache/<hash>.npz 에 PPSD.save_npz 로 저장/재사용 → 동일 요청 재계산 방지.
  • 플로팅 backend/app/services/plotting.py:
    • matplotlib.use("Agg") 후 ppsd.plot(...) 사용.
    • show_percentiles=True, percentiles=[low, high] 로 오버레이.
    • 클리핑 모드는 ppsd.get_percentile(percentile=low/high) 로 곡선을 얻은 뒤 ppsd.current_histogram 을 마스킹하여 자체 pcolormesh 로 렌더 (범위 밖 값은 NaN). 이렇게 오버레이/클리핑 두 모드를 모두 지원.
    • 옵션: xaxis_frequency(주기 vs 주파수), Peterson NLNM/NHNM 오버레이 on/off.
    • savefig(png_path, dpi=120, bbox_inches="tight") → PNG 스트리밍 응답.

API 엔드포인트 backend/app/api/

  • GET /api/health
  • GET /api/networks → [{code, description}]
  • GET /api/stations?network= → [{code, name, lat, lon, ...}]
  • GET /api/channels?network=&station= → [{location, channel, start, end, sample_rate}]
  • POST /api/ppsd (body: PPSDRequest) → {job_id, image_url, stats} 또는 동기 처리 시 곧바로 PNG.
  • GET /api/ppsd/{job_id}.png → 렌더된 PNG.

pydantic 스키마 models/schemas.py

class PPSDRequest(BaseModel):
    network: str
    station: str
    location: str = ""
    channel: str
    starttime: datetime
    endtime: datetime
    percentile_low: float = 10.0
    percentile_high: float = 90.0
    show_overlay: bool = True
    clip_to_percentile: bool = False
    xaxis: Literal["period", "frequency"] = "period"
    show_noise_models: bool = True

설정 config.py

  • FDSNWS_URL=http://172.31.100.100 (환경변수로 오버라이드), CACHE_DIR, CORS_ORIGINS.

비동기/오래 걸리는 계산

  • 초기 구현은 동기 처리 + 요청당 timeout(예: 120s).
  • 확장 여지: BackgroundTasks 또는 Celery/RQ 로 job 큐 전환 지점만 남겨두기 (/api/ppsd 응답 스키마에 job_id 이미 포함).

3. 프론트엔드 (React + Vite + TypeScript)

주요 컴포넌트

  • StationPicker.tsx: 사용자가 선택한 입력 모드(드롭다운 vs 수동)에 따라 network → station → channel 을 순차 드롭다운으로 로드(각 단계에서 /api/networks, /api/stations, /api/channels 호출). "수동 입력" 토글 시 텍스트 인풋으로 전환하여 fallback 제공.
  • PPSDForm.tsx:
    • 시작/종료 시각(<input type="datetime-local"> + UTC 토글).
    • percentile 슬라이더 두 개(하위 0–50, 상위 50–100) 또는 dual-range 슬라이더.
    • 옵션 체크박스: Overlay percentile curves, Clip histogram to percentile range, X-axis: period/frequency, Show Peterson NLNM/NHNM.
  • PPSDResult.tsx:
    • POST /api/ppsd 요청 후 반환된 image_url 을 <img> 로 표시.
    • 로딩 스피너, 에러 표시, 다운로드 버튼(PNG 저장).
    • 계산 통계(사용된 세그먼트 수, 실제 시작/종료 시각) 요약 표기.

API 클라이언트 src/api/client.ts 는 fetch 기반 얇은 래퍼, VITE_API_BASE_URL 환경 변수 사용. dev 환경은 Vite proxy 로 /api → http://localhost:8000 프록시.

UI 참고: IRIS MUSTANG PDF plot 페이지 레이아웃과 유사하게 좌측 컨트롤 패널 + 우측 결과 이미지.
