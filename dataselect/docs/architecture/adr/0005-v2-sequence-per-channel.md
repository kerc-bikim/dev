# 0005. miniSEED 2 시퀀스는 채널별 출력 순

* 상태: Accepted
* 날짜: 2026-08
* 관련: `local_stamp_v2_sequence()`, `local_take_v2seq()`

## 맥락

miniSEED 2 고정 헤더 앞 6바이트는 시퀀스입니다. 입력 시퀀스를 그대로 두면 `-B`가 한 장을 여러 장으로 나눌 때 번호가 반복됩니다. 입력 순이 아니라 **쓰는 시각 순**으로 채널마다 다시 매길 필요가 있습니다.

miniSEED 3 고정 헤더에는 시퀀스 필드가 없습니다.

## 결정

`-B`가 있고 format version이 2일 때만, `writerecord()`가 fwrite / 아카이브 직전에 시퀀스를 찍습니다.

* 키: SourceID (`msr->sid`)
* 값: 해당 채널의 다음 번호, 1부터, 1000000에서 0으로 wrap
* `-B`가 없으면 원본 6바이트를 유지해 복사가 byte-identical로 남습니다

이 브랜치의 맵은 **프로세스(한 번의 실행) × 채널** 입니다. 출력 파일이 바뀌어도 번호가 이어질 수 있습니다.

## 결과

* 장점: `-o` 한 파일에서 채널마다 000001, 000002, … 가 시간순입니다.
* 단점: SDS 날짜 파일이 바뀌어도 시퀀스가 이어질 수 있습니다. 파일별 1부터가 필요하면 맵 키에 출력 경로를 넣어야 합니다.
* 함의: `-o`와 `-A`를 같이 쓰면 같은 packed 버퍼를 두 목적지에 쓰므로 시퀀스 스탬프는 한 번입니다. 두 출력이 같은 번호를 공유합니다.
