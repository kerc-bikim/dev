# dataselect 아키텍처

이 디렉터리는 이 포크의 **dataselect** (EarthScope dataselect 4.3.2 + 로컬 `-B` 확장, 버전 4.4.0) 구조를 세 가지 형식으로 적습니다.

| 문서 | 형식 | 용도 |
|------|------|------|
| [c4.md](c4.md) | [C4](https://c4model.com/) | 시스템·컨테이너·컴포넌트·코드 레벨 다이어그램 |
| [arc42.md](arc42.md) | [arc42](https://arc42.org/) | 요구사항부터 런타임·품질·리스크까지 한 장의 설명 |
| [adr/](adr/) | [ADR](https://adr.github.io/) | 되돌리기 어려운 설계 결정과 그 이유 |

사용법·옵션은 [doc/dataselect.md](../../doc/dataselect.md), 원본 머지는 [UPSTREAM.md](../../UPSTREAM.md) 를 봅니다.

읽는 순서: **C4 컨텍스트 → arc42 1·5·6절 → 관심 있는 ADR**.
